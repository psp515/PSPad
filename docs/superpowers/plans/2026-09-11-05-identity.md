# Identity & Keycloak Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real multi-user identity — built-in accounts plus optional Keycloak sign-in — with a `User` aggregate that provisions a working workspace on first login, and the removal of the temporary header-based identity seam.

**Architecture:** The API validates JWT bearer tokens. Two issuers are accepted: tokens the app itself mints for built-in accounts, and tokens from Keycloak when it is configured. Both land on the same `User` aggregate, matched on `(issuer, subject)`. First sign-in provisions the user: a display name, a time zone, an empty Inbox, and four seeded areas.

**Tech Stack:** .NET 10, ASP.NET Core Identity, JWT bearer, Keycloak 26 (OIDC), Marten, xUnit, Shouldly

**Spec:** `docs/superpowers/specs/2026-09-11-gtd-core-design.md` §10

## Global Constraints

- .NET 10 (LTS). All projects target `net10.0`.
- `PSPad.Domain` and `PSPad.Contracts` reference no infrastructure packages.
- PostgreSQL 17. Marten 8.x. xUnit + Shouldly.
- Every query filters by the signed-in user — there is no sharing in this slice.
- All stored instants are UTC `DateTimeOffset`; the user's time zone lives on the `User` aggregate.
- Code, comments, commits and docs in English.
- GPL v3 — every dependency must be license-compatible.

**Depends on:** plans 01 (Keycloak in compose), 02 (domain patterns), 04 (endpoints, `CurrentUser` seam).

`src/PSPad.Domain/Users/UserDecider.cs`:

```csharp
using PSPad.Domain.Common;

namespace PSPad.Domain.Users;

public static class UserDecider
{
    const int MaxNameLength = 100;

    public static IReadOnlyList<IDomainEvent> Decide(UserState? state, ICommand command) =>
        command switch
        {
            RegisterUser register => Register(state, register),
            SetTimeZone zone => ChangeZone(Require(state), zone),
            SetDisplayName name => ChangeName(Require(state), name),
            _ => []
        };

    static IReadOnlyList<IDomainEvent> Register(UserState? state, RegisterUser command)
    {
        if (state is not null)
            return [];

        var name = Text.Required(command.DisplayName, MaxNameLength);
        ValidateZone(command.TimeZoneId);

        return [new UserRegistered(
            command.UserId, command.IssuedAt, command.CommandId,
            command.SubjectUserId, command.Issuer, command.Subject, name, command.TimeZoneId)];
    }

    static IReadOnlyList<IDomainEvent> ChangeZone(UserState state, SetTimeZone command)
    {
        ValidateZone(command.TimeZoneId);

        return command.TimeZoneId == state.TimeZoneId
            ? []
            : [new TimeZoneSet(
                command.UserId, command.IssuedAt, command.CommandId,
                state.Id, command.TimeZoneId)];
    }

    static IReadOnlyList<IDomainEvent> ChangeName(UserState state, SetDisplayName command)
    {
        var name = Text.Required(command.DisplayName, MaxNameLength);

        return name == state.DisplayName
            ? []
            : [new DisplayNameSet(
                command.UserId, command.IssuedAt, command.CommandId, state.Id, name)];
    }

    /// <summary>
    /// TimeZoneInfo is part of the base class library and is available in
    /// WebAssembly, so this check does not break domain purity (AD-4).
    /// </summary>
    static void ValidateZone(string timeZoneId)
    {
        try
        {
            TimeZoneInfo.FindSystemTimeZoneById(timeZoneId);
        }
        catch (Exception exception) when (
            exception is TimeZoneNotFoundException or InvalidTimeZoneException)
        {
            throw new DomainException(
                ErrorCodes.InvalidTimeZone, $"Unknown time zone \"{timeZoneId}\".");
        }
    }

    static UserState Require(UserState? state) =>
        state ?? throw new DomainException(ErrorCodes.NotFound, "User does not exist.");

    public static UserState? Apply(UserState? state, IDomainEvent @event) =>
        (state, @event) switch
        {
            (_, UserRegistered e) => new UserState(
                e.SubjectUserId, e.Issuer, e.Subject, e.DisplayName, e.TimeZoneId),
            ({ } s, TimeZoneSet e) => s with { TimeZoneId = e.TimeZoneId },
            ({ } s, DisplayNameSet e) => s with { DisplayName = e.DisplayName },
            _ => state
        };
}
```

`src/PSPad.Server/Identity/UserProvisioner.cs`:

```csharp
using Marten;
using PSPad.Domain.Areas;
using PSPad.Domain.Common;
using PSPad.Domain.Users;
using PSPad.Server.Commands;
using PSPad.Server.Projections;

namespace PSPad.Server.Identity;

public static class UserProvisioner
{
    static readonly string[] SeedAreas = ["Life", "Work", "Studies", "Projects"];

    /// <summary>
    /// Finds the user behind an (issuer, subject) pair, creating them on first
    /// sign-in together with four starter areas (spec §10). Does not commit —
    /// the caller owns the transaction.
    /// </summary>
    public static async Task<UserId> EnsureAsync(
        IDocumentSession session,
        string issuer,
        string subject,
        string displayName,
        string timeZoneId,
        CancellationToken cancellationToken)
    {
        var existing = await session.Query<UserView>()
            .Where(view => view.Issuer == issuer && view.Subject == subject)
            .FirstOrDefaultAsync(cancellationToken);

        if (existing is not null)
            return new UserId(existing.Id);

        var userId = UserId.New();
        var now = DateTimeOffset.UtcNow;

        await CommandProcessor.ExecuteAsync(
            session,
            new RegisterUser(
                userId, Guid.NewGuid(), now, userId, issuer, subject, displayName, timeZoneId),
            cancellationToken);

        foreach (var (name, order) in SeedAreas.Select((name, index) => (name, index)))
            await CommandProcessor.ExecuteAsync(
                session,
                new CreateArea(userId, Guid.NewGuid(), now, AreaId.New(), name, order),
                cancellationToken);

        return userId;
    }
}
```

`src/PSPad.Server/Identity/AuthenticationSetup.cs`:

```csharp
using System.Text;
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.IdentityModel.Tokens;

namespace PSPad.Server.Identity;

public static class AuthenticationSetup
{
    public const string LocalScheme = "local";
    public const string KeycloakScheme = "keycloak";

    public static void Add(WebApplicationBuilder builder)
    {
        var signingKey = builder.Configuration["Jwt:SigningKey"]
            ?? throw new InvalidOperationException("Jwt:SigningKey is not configured.");

        var issuer = builder.Configuration["Jwt:Issuer"] ?? "pspad-local";
        var keycloakAuthority = builder.Configuration["Keycloak:Authority"];

        var authentication = builder.Services
            .AddAuthentication(LocalScheme)
            .AddJwtBearer(LocalScheme, options =>
            {
                options.TokenValidationParameters = new TokenValidationParameters
                {
                    ValidateIssuer = true,
                    ValidIssuer = issuer,
                    ValidateAudience = false,
                    ValidateIssuerSigningKey = true,
                    IssuerSigningKey = new SymmetricSecurityKey(
                        Encoding.UTF8.GetBytes(signingKey))
                };
            });

        if (!string.IsNullOrWhiteSpace(keycloakAuthority))
            authentication.AddJwtBearer(KeycloakScheme, options =>
            {
                options.Authority = keycloakAuthority;
                options.Audience = builder.Configuration["Keycloak:Audience"] ?? "pspad-api";

                // Self-hosted Keycloak commonly runs behind plain HTTP inside the
                // compose network; TLS is terminated at the reverse proxy.
                options.RequireHttpsMetadata =
                    builder.Configuration.GetValue("Keycloak:RequireHttps", true);
            });

        builder.Services.AddAuthorization(options =>
            options.DefaultPolicy = new Microsoft.AspNetCore.Authorization
                    .AuthorizationPolicyBuilder(SchemesInUse(keycloakAuthority))
                .RequireAuthenticatedUser()
                .Build());
    }

    static string[] SchemesInUse(string? keycloakAuthority) =>
        string.IsNullOrWhiteSpace(keycloakAuthority)
            ? [LocalScheme]
            : [LocalScheme, KeycloakScheme];
}
```

`src/PSPad.Server/Api/CurrentUser.cs` (replacing the header version entirely):

```csharp
using System.Security.Claims;
using Marten;
using PSPad.Domain.Common;
using PSPad.Server.Identity;

namespace PSPad.Server.Api;

public static class CurrentUser
{
    /// <summary>
    /// Maps the authenticated principal onto a PSPad user, provisioning on first
    /// sign-in. Returns null when the request carries no valid token.
    /// </summary>
    public static async Task<UserId?> ResolveAsync(
        HttpContext context, IDocumentSession session, CancellationToken cancellationToken)
    {
        if (context.User.Identity?.IsAuthenticated != true)
            return null;

        var issuer = context.User.FindFirstValue("iss")
            ?? context.User.Claims.FirstOrDefault()?.Issuer
            ?? AuthenticationSetup.LocalScheme;

        var subject = context.User.FindFirstValue(ClaimTypes.NameIdentifier)
            ?? context.User.FindFirstValue("sub");

        if (string.IsNullOrWhiteSpace(subject))
            return null;

        var displayName = context.User.FindFirstValue("name")
            ?? context.User.FindFirstValue(ClaimTypes.Name)
            ?? subject;

        var timeZoneId = context.Request.Headers["X-Time-Zone"].ToString();

        if (string.IsNullOrWhiteSpace(timeZoneId))
            timeZoneId = "UTC";

        return await UserProvisioner.EnsureAsync(
            session, issuer, subject, displayName, timeZoneId, cancellationToken);
    }
}
```

- [ ] **Step 7: Write the local token endpoint**

`src/PSPad.Server/Identity/TokenEndpoints.cs`:

```csharp
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Text;
using Marten;
using Microsoft.AspNetCore.Identity;
using Microsoft.IdentityModel.Tokens;

namespace PSPad.Server.Identity;

public sealed class LocalAccount
{
    public string Id { get; set; } = string.Empty;      // the username
    public string PasswordHash { get; set; } = string.Empty;
    public string DisplayName { get; set; } = string.Empty;
}

public sealed record TokenRequest(string Username, string Password);

public sealed record TokenResponse(string AccessToken, DateTimeOffset ExpiresAt);

public static class TokenEndpoints
{
    public static void MapTokenEndpoints(this WebApplication app)
    {
        app.MapPost("/api/auth/token", async (
            TokenRequest request,
            IDocumentSession session,
            IConfiguration configuration,
            CancellationToken cancellationToken) =>
        {
            var hasher = new PasswordHasher<LocalAccount>();
            var account = await session.LoadAsync<LocalAccount>(request.Username, cancellationToken);

            if (account is null)
            {
                // Self-hosted, single-household deployment: the first sign-in with
                // a username claims it. Registration is not a separate flow.
                account = new LocalAccount
                {
                    Id = request.Username,
                    DisplayName = request.Username
                };
                account.PasswordHash = hasher.HashPassword(account, request.Password);

                session.Store(account);
                await session.SaveChangesAsync(cancellationToken);
            }
            else if (hasher.VerifyHashedPassword(account, account.PasswordHash, request.Password)
                     == PasswordVerificationResult.Failed)
            {
                return Results.Unauthorized();
            }

            var expiresAt = DateTimeOffset.UtcNow.AddDays(30);
            var token = Issue(configuration, account, expiresAt);

            return Results.Ok(new TokenResponse(token, expiresAt));
        }).AllowAnonymous();
    }

    static string Issue(IConfiguration configuration, LocalAccount account, DateTimeOffset expiresAt)
    {
        var key = new SymmetricSecurityKey(
            Encoding.UTF8.GetBytes(configuration["Jwt:SigningKey"]!));

        var descriptor = new JwtSecurityToken(
            issuer: configuration["Jwt:Issuer"] ?? "pspad-local",
            claims:
            [
                new Claim(JwtRegisteredClaimNames.Sub, account.Id),
                new Claim("name", account.DisplayName)
            ],
            expires: expiresAt.UtcDateTime,
            signingCredentials: new SigningCredentials(key, SecurityAlgorithms.HmacSha256));

        return new JwtSecurityTokenHandler().WriteToken(descriptor);
    }
}
```

A 30-day token on a self-hosted personal app keeps the phone signed in between
uses. Shorten it here if that trade-off ever stops being acceptable.
