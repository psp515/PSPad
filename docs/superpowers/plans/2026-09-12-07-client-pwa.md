# Client PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Blazor WebAssembly PWA that signs in through Keycloak and drives the
whole GTD core — Today, Inbox, areas, lists, task detail, goals and history —
served from its own nginx image.

**Architecture:** The client holds an in-memory replica of the user's aggregates
and sends commands to `/api/commands`. It references `PSPad.Module.Tasks`, so the
Today screen runs the same `TodayRule` the server runs; no screen re-implements a
rule. Plan 08 swaps the in-memory replica for IndexedDB and adds the outbox — the
seam for that is `IReplica`, introduced here.

**Tech Stack:** .NET 10 Blazor WebAssembly, MudBlazor, `Microsoft.AspNetCore.
Components.WebAssembly.Authentication` (OIDC, code + PKCE), bUnit, xUnit v3,
nginx.

**Spec:** `docs/superpowers/specs/2026-09-12-slice-1-design.md`

## Global Constraints

- Target framework `net10.0`, `Nullable` enable, `TreatWarningsAsErrors` true.
- No comments in code or markup, except one line for a genuinely counter-intuitive constraint saying *why*.
- Every test class carries `[UnitTest]`. This plan has no integration tests.
- `PSPad.App` references `PSPad.Module.Tasks`, `PSPad.Abstractions` and `PSPad.Contracts`. Never `PSPad.Infrastructure`.
- No screen re-implements a domain rule. Today comes from `TodayRule.Select`, occurrence status from `Occurrences.Between`.
- A star sorts up. It never puts a task on Today.
- The image is static: the API base URL and Keycloak settings are substituted at container start, never baked in.
- Code, comments, commits and docs in English.

```csharp
using PSPad.Abstractions;

namespace PSPad.App.State;

public interface IReplica
{
    Task<T?> LoadAsync<T>(Guid id) where T : Aggregate;

    Task<IReadOnlyList<T>> LoadAllAsync<T>(Guid userId) where T : Aggregate;

    Task SaveAsync(Aggregate aggregate);

    Task<long> MarkerAsync();

    Task SetMarkerAsync(long marker);
}
```

```csharp
using PSPad.Abstractions;

namespace PSPad.App.State;

public sealed class InMemoryReplica : IReplica
{
    readonly Dictionary<Guid, Aggregate> _documents = [];
    long _marker;

    public Task<T?> LoadAsync<T>(Guid id) where T : Aggregate =>
        Task.FromResult(_documents.GetValueOrDefault(id) as T);

    public Task<IReadOnlyList<T>> LoadAllAsync<T>(Guid userId) where T : Aggregate =>
        Task.FromResult<IReadOnlyList<T>>(
            _documents.Values.OfType<T>().Where(document => document.UserId == userId).ToArray());

    public Task SaveAsync(Aggregate aggregate)
    {
        _documents[aggregate.Id] = aggregate;
        return Task.CompletedTask;
    }

    public Task<long> MarkerAsync() => Task.FromResult(_marker);

    public Task SetMarkerAsync(long marker)
    {
        _marker = marker;
        return Task.CompletedTask;
    }
}
```

```csharp
using PSPad.Abstractions;

namespace PSPad.App.State;

public sealed class ReplicaDocumentStore<T>(IReplica replica) : IDocumentStore<T> where T : Aggregate
{
    public Task<T?> LoadAsync(Guid id, CancellationToken ct) => replica.LoadAsync<T>(id);

    public Task<IReadOnlyList<T>> LoadAllAsync(Guid userId, CancellationToken ct) =>
        replica.LoadAllAsync<T>(userId);
}
```

- [ ] **Step 4: Write the API client and the unit of work**

```csharp
using System.Net.Http.Json;
using PSPad.Contracts;

namespace PSPad.App.Api;

public sealed class PSPadApiClient(HttpClient http)
{
    public async Task<MeResponse?> MeAsync() =>
        await http.GetFromJsonAsync<MeResponse>("api/me");

    public async Task<IReadOnlyList<CommandResponse>> SendAsync(IReadOnlyList<CommandEnvelope> envelopes)
    {
        var response = await http.PostAsJsonAsync("api/commands", envelopes);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<CommandResponse[]>() ?? [];
    }

    public async Task<SyncResponse?> SyncAsync(long since) =>
        await http.GetFromJsonAsync<SyncResponse>($"api/sync?since={since}");

    public async Task<IReadOnlyList<HistoryEntry>> HistoryAsync(long? before, int limit)
    {
        var query = before is null ? $"api/history?limit={limit}" : $"api/history?limit={limit}&before={before}";
        return await http.GetFromJsonAsync<HistoryEntry[]>(query) ?? [];
    }
}
```

```csharp
using System.Text.Json;
using PSPad.Abstractions;
using PSPad.App.Api;
using PSPad.Contracts;

namespace PSPad.App.State;

public sealed class ReplicaUnitOfWork(IReplica replica, PSPadApiClient api) : IUnitOfWork
{
    readonly List<Aggregate> _staged = [];
    readonly List<CommandEnvelope> _pending = [];

    public IReadOnlyList<CommandResponse> LastResponses { get; private set; } = [];

    public void Stage(Aggregate aggregate, IReadOnlyList<DomainEvent> events) => _staged.Add(aggregate);

    public void Queue(ICommand command) =>
        _pending.Add(new CommandEnvelope(
            command.GetType().Name, JsonSerializer.SerializeToElement(command, command.GetType())));

    public async Task CommitAsync(Guid commandId, Guid userId, CancellationToken ct)
    {
        foreach (var aggregate in _staged)
        {
            await replica.SaveAsync(aggregate);
        }

        _staged.Clear();

        if (_pending.Count > 0)
        {
            LastResponses = await api.SendAsync(_pending);
            _pending.Clear();
        }
    }
}
```

- [ ] **Step 5: Write the command sender the pages use**

`src/PSPad.App/State/CommandSender.cs`:

```csharp
using PSPad.Abstractions;
using PSPad.App.State;

namespace PSPad.App.State;

public sealed class CommandSender(IServiceProvider services, ReplicaUnitOfWork work)
{
    public async Task<CommandResult> SendAsync<TCommand>(TCommand command, CancellationToken ct = default)
        where TCommand : ICommand
    {
        work.Queue(command);
        var handler = services.GetService(typeof(ICommandHandler<TCommand>)) as ICommandHandler<TCommand>;

        return handler is null
            ? CommandResult.Rejected($"No handler for {typeof(TCommand).Name}.")
            : await handler.HandleAsync(command, ct);
    }
}
```

The handler runs locally first, so the screen updates before the network does.
The queued envelope goes to the server inside the same commit — the local result
and the server result are the same decision run twice, which is the point of
sharing the module.

### Task 6: nginx image and runtime configuration

**Files:**
- Create: `src/PSPad.App/Dockerfile`
- Create: `docker/nginx/pspad.conf`
- Create: `src/PSPad.App/wwwroot/appsettings.template.json`
- Create: `src/PSPad.App/docker-entrypoint.sh`
- Modify: `docker/compose.prod.yaml`
- Modify: `docker/.env.example`
- Modify: `README.md`

**Interfaces:**
- Consumes: the published `wwwroot` from Task 1.
- Produces: image `pspad-app:local` serving on port 8080, configured by `API_BASE_ADDRESS`, `KEYCLOAK_AUTHORITY` and `KEYCLOAK_CLIENT_ID` at container start.

- [ ] **Step 1: Write the nginx configuration**

`docker/nginx/pspad.conf`:

```nginx
server {
    listen 8080;
    root /usr/share/nginx/html;

    gzip_static on;

    types {
        application/wasm wasm;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(?:wasm|dll|dat|blat|js|css)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    location = /index.html {
        add_header Cache-Control "no-cache";
    }

    location = /service-worker.js {
        add_header Cache-Control "no-cache";
    }
}
```

`index.html` and the service worker must not be cached, or a deployed update
never reaches a browser that already has the old pair.

- [ ] **Step 2: Write the runtime configuration template**

`src/PSPad.App/wwwroot/appsettings.template.json`:

```json
{
  "Api": {
    "BaseAddress": "${API_BASE_ADDRESS}"
  },
  "Keycloak": {
    "Authority": "${KEYCLOAK_AUTHORITY}",
    "ClientId": "${KEYCLOAK_CLIENT_ID}",
    "PostLogoutRedirectUri": "/authentication/logout-callback",
    "RedirectUri": "/authentication/login-callback"
  }
}
```

`src/PSPad.App/docker-entrypoint.sh`:

```sh
#!/bin/sh
set -e
envsubst < /usr/share/nginx/html/appsettings.template.json > /usr/share/nginx/html/appsettings.json
exec nginx -g 'daemon off;'
```

- [ ] **Step 3: Write the image**

`src/PSPad.App/Dockerfile`:

```dockerfile
FROM mcr.microsoft.com/dotnet/sdk:10.0 AS build
WORKDIR /src
COPY Directory.Build.props ./
COPY src/ src/
RUN dotnet publish src/PSPad.App/PSPad.App.csproj -c Release -o /app

FROM nginx:alpine
RUN apk add --no-cache gettext
COPY --from=build /app/wwwroot /usr/share/nginx/html
COPY docker/nginx/pspad.conf /etc/nginx/conf.d/default.conf
COPY src/PSPad.App/docker-entrypoint.sh /docker-entrypoint.d/pspad.sh
RUN chmod +x /docker-entrypoint.d/pspad.sh
EXPOSE 8080
```

The stock `nginx` image runs every executable in `/docker-entrypoint.d` before
starting, so the substitution happens without replacing the image's own
entrypoint. Drop the `exec nginx` line from the script when using that directory
— it must return, not take over.

- [ ] **Step 4: Build and run the image**

```bash
docker build -f src/PSPad.App/Dockerfile -t pspad-app:local .
docker run --rm -p 5001:8080 \
  -e API_BASE_ADDRESS=http://localhost:5000 \
  -e KEYCLOAK_AUTHORITY=http://localhost:8080/realms/pspad \
  -e KEYCLOAK_CLIENT_ID=pspad-app \
  pspad-app:local &
curl -s localhost:5001/appsettings.json
```

Expected: the substituted JSON, with no `${...}` left in it. Open
`http://localhost:5001` and confirm the app loads and signs in.

- [ ] **Step 5: Add the service to the production stack**

In `docker/compose.prod.yaml`:

```yaml
  app:
    build:
      context: ..
      dockerfile: src/PSPad.App/Dockerfile
    image: pspad-app:local
    environment:
      API_BASE_ADDRESS: ${API_BASE_ADDRESS}

      KEYCLOAK_CLIENT_ID: ${KEYCLOAK_CLIENT_ID}
    ports:
      - "5001:8080"
    depends_on:
      - api
    networks: [pspad]
```

Add `API_BASE_ADDRESS`, `KEYCLOAK_CLIENT_ID` to `docker/.env.example`, and
document both images in `README.md`.
