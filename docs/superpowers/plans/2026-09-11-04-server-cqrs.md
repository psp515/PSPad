# Server, CQRS & Projections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A server that accepts batches of domain commands, stores the resulting events in Marten, maintains the read models every screen needs, and serves them — including the computed Today view and the sync delta the offline client depends on.

**Architecture:** Each aggregate instance is one Marten event stream keyed by its aggregate id. A command is routed to its stream, the state is folded from the stream with the domain's `Apply`, the domain's `Decide` produces events, and those events are appended — each to the stream it belongs to, so one command may touch two aggregates in one transaction. Inline Marten projections build the read models; every projection row records the event sequence that last touched it, which is the version marker the sync endpoint pages by.

**Tech Stack:** .NET 10, Marten 8.x, Wolverine 4.x, PostgreSQL 17, ASP.NET Core minimal APIs, xUnit, Shouldly

**Spec:** `docs/superpowers/specs/2026-09-11-gtd-core-design.md`

## Global Constraints

- .NET 10 (LTS). All projects target `net10.0`.
- `PSPad.Domain` and `PSPad.Contracts` reference no infrastructure packages — all Marten and Wolverine code lives in `PSPad.Server`.
- PostgreSQL 17. Marten 8.x. Wolverine 4.x. xUnit + Shouldly.
- All user-facing dates are `DateOnly` in the user's time zone; all stored instants are UTC `DateTimeOffset`.
- No audit table — history comes from the event stream.
- Server tests run against the real `postgres-test` compose service, never an in-memory fake.
- Code, comments, commits and docs in English.
- GPL v3 — every dependency must be license-compatible.

**Depends on:** plans 01 (compose, test fixture), 02 (aggregates), 03 (recurrence, Today rule).

**API drift note:** Marten and Wolverine registration APIs move between major
versions. If a signature below does not compile, check the installed package's
API and adapt — the *shape* of each task (what is stored, what is projected,
what is asserted) is the requirement, not the exact call.

```csharp
using Marten;
using Marten.Events;
using PSPad.Domain;
using PSPad.Domain.Common;
using Weasel.Core;

namespace PSPad.Server.Infrastructure;

public static class MartenConfiguration
{
    public static void Configure(StoreOptions options, string connectionString)
    {
        options.Connection(connectionString);
        options.AutoCreateSchemaObjects = AutoCreate.CreateOrUpdate;

        // One stream per aggregate instance, keyed by the aggregate's Guid.
        options.Events.StreamIdentity = StreamIdentity.AsGuid;

        // Register every domain event so Marten stores a stable type alias
        // instead of an assembly-qualified name.
        foreach (var eventType in DomainEventTypes())
            options.Events.AddEventType(eventType);

        options.UseSystemTextJsonForSerialization();
    }

    public static IEnumerable<Type> DomainEventTypes() =>
        typeof(DomainMarker).Assembly
            .GetTypes()
            .Where(type => type is { IsAbstract: false, IsInterface: false })
            .Where(type => typeof(IDomainEvent).IsAssignableFrom(type));
}
```

```csharp
using Marten;
using PSPad.Domain.Common;

namespace PSPad.Server.Infrastructure;

public static class AggregateStore
{
    /// <summary>
    /// Rebuilds aggregate state by folding its stream with the domain's own
    /// Apply function — the same function the WASM client folds with (AD-3).
    /// </summary>
    public static async Task<TState?> LoadAsync<TState>(
        IQuerySession session,
        Guid streamId,
        Func<TState?, IDomainEvent, TState?> apply,
        CancellationToken cancellationToken)
        where TState : class
    {
        var events = await session.Events.FetchStreamAsync(streamId, token: cancellationToken);

        TState? state = null;

        foreach (var stored in events)
            if (stored.Data is IDomainEvent domainEvent)
                state = apply(state, domainEvent);

        return state;
    }
}
```

```csharp
using PSPad.Domain.Areas;
using PSPad.Domain.Common;
using PSPad.Domain.Goals;
using PSPad.Domain.Inbox;
using PSPad.Domain.Lists;
using PSPad.Domain.Tasks;

namespace PSPad.Server.Commands;

public enum AggregateKind
{
    Area,
    List,
    Task,
    Goal,
    Inbox
}

public static class CommandRouting
{
    public static AggregateKind AggregateOf(ICommand command) => command switch
    {
        CreateArea or RenameArea or ArchiveArea => AggregateKind.Area,
        CreateList or RenameList or ArchiveList => AggregateKind.List,
        CreateGoal or EditGoal or ArchiveGoal => AggregateKind.Goal,
        CaptureToInbox or OrganizeInboxItem or DeleteInboxItem => AggregateKind.Inbox,
        _ when IsTaskCommand(command) => AggregateKind.Task,
        _ => throw Unknown(command.GetType())
    };

    public static Guid StreamOf(ICommand command) => command switch
    {
        CreateArea c => c.AreaId.Value,
        RenameArea c => c.AreaId.Value,
        ArchiveArea c => c.AreaId.Value,
        CreateList c => c.ListId.Value,
        RenameList c => c.ListId.Value,
        ArchiveList c => c.ListId.Value,
        CreateGoal c => c.GoalId.Value,
        EditGoal c => c.GoalId.Value,
        ArchiveGoal c => c.GoalId.Value,
        CaptureToInbox c => c.UserId.Value,
        OrganizeInboxItem c => c.UserId.Value,
        DeleteInboxItem c => c.UserId.Value,
        _ when TaskIdOf(command) is { } taskId => taskId.Value,
        _ => throw Unknown(command.GetType())
    };

    public static Guid StreamOf(IDomainEvent @event) => @event switch
    {
        AreaCreated e => e.AreaId.Value,
        AreaRenamed e => e.AreaId.Value,
        AreaArchived e => e.AreaId.Value,
        ListCreated e => e.ListId.Value,
        ListRenamed e => e.ListId.Value,
        ListArchived e => e.ListId.Value,
        GoalCreated e => e.GoalId.Value,
        GoalEdited e => e.GoalId.Value,
        GoalArchived e => e.GoalId.Value,
        InboxItemCaptured e => e.UserId.Value,
        InboxItemOrganized e => e.UserId.Value,
        InboxItemDeleted e => e.UserId.Value,
        _ when TaskIdOfEvent(@event) is { } taskId => taskId.Value,
        _ => throw Unknown(@event.GetType())
    };

    static bool IsTaskCommand(ICommand command) => TaskIdOf(command) is not null;

    /// <summary>
    /// Every task command carries a TaskId property. Reading it reflectively
    /// keeps this router from growing an arm per command as the task aggregate
    /// gains behavior.
    /// </summary>
    static TaskId? TaskIdOf(ICommand command) =>
        command.GetType().GetProperty(nameof(CreateTask.TaskId))?.GetValue(command) as TaskId?;

    static TaskId? TaskIdOfEvent(IDomainEvent @event) =>
        @event.GetType().GetProperty(nameof(TaskCreated.TaskId))?.GetValue(@event) as TaskId?;

    static InvalidOperationException Unknown(Type type) =>
        new($"No stream routing is defined for {type.Name}. Add it to CommandRouting.");
}
```

`src/PSPad.Server/Commands/CommandProcessor.cs`:

```csharp
using Marten;
using PSPad.Domain.Areas;
using PSPad.Domain.Common;
using PSPad.Domain.Goals;
using PSPad.Domain.Inbox;
using PSPad.Domain.Lists;
using PSPad.Domain.Tasks;
using PSPad.Server.Infrastructure;

namespace PSPad.Server.Commands;

public static class CommandProcessor
{
    /// <summary>
    /// Loads the target aggregate, asks the domain to decide, and appends the
    /// resulting events — each to the stream it belongs to, so a command that
    /// touches two aggregates stays one transaction. Does not call
    /// SaveChangesAsync: the caller commits the whole batch.
    /// </summary>
    public static async Task<CommandResult> ExecuteAsync(
        IDocumentSession session, ICommand command, CancellationToken cancellationToken)
    {
        var already = await session.LoadAsync<ProcessedCommand>(command.CommandId, cancellationToken);

        if (already is not null)
            return CommandResult.Ok(command.CommandId);

        IReadOnlyList<IDomainEvent> events;

        try
        {
            events = await DecideAsync(session, command, cancellationToken);
        }
        catch (DomainException exception)
        {
            return CommandResult.Rejected(command.CommandId, exception.Code, exception.Message);
        }

        foreach (var group in events.GroupBy(CommandRouting.StreamOf))
            session.Events.Append(group.Key, group.Cast<object>().ToArray());

        session.Store(new ProcessedCommand(
            command.CommandId, command.UserId, DateTimeOffset.UtcNow));

        return CommandResult.Ok(command.CommandId);
    }

    static async Task<IReadOnlyList<IDomainEvent>> DecideAsync(
        IDocumentSession session, ICommand command, CancellationToken cancellationToken)
    {
        var stream = CommandRouting.StreamOf(command);

        return CommandRouting.AggregateOf(command) switch
        {
            AggregateKind.Area => AreaDecider.Decide(
                await AggregateStore.LoadAsync<AreaState>(
                    session, stream, AreaDecider.Apply, cancellationToken),
                command),

            AggregateKind.List => TaskListDecider.Decide(
                await AggregateStore.LoadAsync<TaskListState>(
                    session, stream, TaskListDecider.Apply, cancellationToken),
                command),

            AggregateKind.Goal => GoalDecider.Decide(
                await AggregateStore.LoadAsync<GoalState>(
                    session, stream, GoalDecider.Apply, cancellationToken),
                command),

            AggregateKind.Task => TodoTaskDecider.Decide(
                await AggregateStore.LoadAsync<TodoTaskState>(
                    session, stream, TodoTaskDecider.Apply, cancellationToken),
                command),

            AggregateKind.Inbox => InboxDecider.Decide(
                await LoadInboxAsync(session, command.UserId, cancellationToken),
                command),

            _ => []
        };
    }

    static async Task<InboxState> LoadInboxAsync(
        IDocumentSession session, UserId userId, CancellationToken cancellationToken)
    {
        var empty = new InboxState(userId, []);
        var events = await session.Events.FetchStreamAsync(userId.Value, token: cancellationToken);

        var state = empty;

        foreach (var stored in events)
            if (stored.Data is IDomainEvent domainEvent)
                state = InboxDecider.Apply(state, domainEvent);

        return state;
    }
}
```

The Inbox fold is separate because its state is never null — a user always has an
Inbox, even an empty one (spec §3.1).

```csharp
using Marten.Events;
using Marten.Events.Aggregation;
using PSPad.Domain.Tasks;

namespace PSPad.Server.Projections;

/// <summary>
/// Rebuilds TaskView from the task's own stream. Every apply stamps Version with
/// the event sequence, which is the sync marker of spec §9.5.
/// </summary>
public sealed class TaskViewProjection : SingleStreamProjection<TaskView, Guid>
{
    public static TaskView Create(IEvent<TaskCreated> e) => new()
    {
        Id = e.Data.TaskId.Value,
        UserId = e.Data.UserId,
        ListId = e.Data.ListId,
        Name = e.Data.Name,
        DueDate = e.Data.DueDate,
        Priority = e.Data.Priority,
        GoalId = e.Data.GoalId,
        Version = e.Sequence
    };

    public static void Apply(IEvent<TaskRenamed> e, TaskView view)
    {
        view.Name = e.Data.Name;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskDueDateSet> e, TaskView view)
    {
        view.DueDate = e.Data.DueDate;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskPrioritySet> e, TaskView view)
    {
        view.Priority = e.Data.Priority;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskStarred> e, TaskView view)
    {
        view.Starred = true;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskUnstarred> e, TaskView view)
    {
        view.Starred = false;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskLinkedToGoal> e, TaskView view)
    {
        view.GoalId = e.Data.GoalId;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskUnlinkedFromGoal> e, TaskView view)
    {
        view.GoalId = null;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskMovedToList> e, TaskView view)
    {
        view.ListId = e.Data.ListId;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskCompleted> e, TaskView view)
    {
        view.Completed = true;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<TaskReopened> e, TaskView view)
    {
        view.Completed = false;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<RecurrenceSet> e, TaskView view)
    {
        view.Recurrence = e.Data.Rule;
        view.DueDate = null;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<RecurrenceCleared> e, TaskView view)
    {
        view.Recurrence = null;
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<OccurrenceCompleted> e, TaskView view)
    {
        if (!view.CompletedDays.Contains(e.Data.Date))
            view.CompletedDays.Add(e.Data.Date);

        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<OccurrenceUncompleted> e, TaskView view)
    {
        view.CompletedDays.Remove(e.Data.Date);
        view.Version = e.Sequence;
    }

    public static void Apply(IEvent<StepAdded> e, TaskView view)
    {
        view.Steps.Add(new StepRow
        {
            Id = e.Data.StepId,
            Text = e.Data.Text,
            DueDate = e.Data.DueDate,
            Position = e.Data.Position
        });

        RefreshNextStep(view, e.Sequence);
    }

    public static void Apply(IEvent<StepEdited> e, TaskView view)
    {
        var step = view.Steps.Single(s => s.Id == e.Data.StepId);
        step.Text = e.Data.Text;
        step.DueDate = e.Data.DueDate;

        RefreshNextStep(view, e.Sequence);
    }

    public static void Apply(IEvent<StepCompleted> e, TaskView view)
    {
        view.Steps.Single(s => s.Id == e.Data.StepId).Completed = true;
        RefreshNextStep(view, e.Sequence);
    }

    public static void Apply(IEvent<StepUncompleted> e, TaskView view)
    {
        view.Steps.Single(s => s.Id == e.Data.StepId).Completed = false;
        RefreshNextStep(view, e.Sequence);
    }

    public static void Apply(IEvent<StepRemoved> e, TaskView view)
    {
        view.Steps.RemoveAll(s => s.Id == e.Data.StepId);

        foreach (var (step, index) in view.Steps.OrderBy(s => s.Position).Select((s, i) => (s, i)))
            step.Position = index;

        RefreshNextStep(view, e.Sequence);
    }

    public static void Apply(IEvent<StepsReordered> e, TaskView view)
    {
        foreach (var (id, index) in e.Data.Order.Select((id, i) => (id, i)))
            view.Steps.Single(s => s.Id == id).Position = index;

        RefreshNextStep(view, e.Sequence);
    }

    /// <summary>Flattens the first unchecked step onto the row (spec §8).</summary>
    static void RefreshNextStep(TaskView view, long sequence)
    {
        var next = view.Steps
            .Where(step => !step.Completed)
            .OrderBy(step => step.Position)
            .FirstOrDefault();

        view.NextStepText = next?.Text;
        view.NextStepDate = next?.DueDate;
        view.Version = sequence;
    }
}
```

```csharp
using Marten;
using PSPad.Domain.Common;
using PSPad.Domain.Tasks;
using PSPad.Domain.Today;
using PSPad.Server.Projections;

namespace PSPad.Server.Today;

public static class TodayQuery
{
    /// <summary>
    /// Spec §5. "Today" is resolved in the user's own time zone, never the
    /// server's. The rule itself lives in the domain — this only feeds it rows
    /// and sorts the survivors.
    /// </summary>
    public static async Task<IReadOnlyList<TodayRow>> RunAsync(
        IQuerySession session,
        UserId userId,
        TimeZoneInfo zone,
        DateTimeOffset now,
        CancellationToken cancellationToken)
    {
        var today = DateOnly.FromDateTime(TimeZoneInfo.ConvertTime(now, zone).DateTime);

        var tasks = await session.Query<TaskView>()
            .Where(view => view.UserId == userId && !view.Completed)
            .ToListAsync(cancellationToken);

        var lists = (await session.Query<ListView>()
                .Where(view => view.UserId == userId)
                .ToListAsync(cancellationToken))
            .ToDictionary(view => new ListId(view.Id));

        var areas = (await session.Query<AreaView>()
                .Where(view => view.UserId == userId)
                .ToListAsync(cancellationToken))
            .ToDictionary(view => new AreaId(view.Id));

        var rows = new List<(TodayRow Row, TodayVerdict Verdict)>();

        foreach (var task in tasks)
        {
            var candidate = new TodayCandidate(
                new TaskId(task.Id),
                task.Name,
                task.DueDate,
                task.NextStepDate,
                task.Priority,
                task.Starred,
                task.Completed,
                task.Recurrence,
                task.CompletedDays);

            if (TodayRule.Evaluate(candidate, today) is not { } verdict)
                continue;

            if (!lists.TryGetValue(task.ListId, out var list))
                continue;

            var areaName = areas.TryGetValue(list.AreaId, out var area) ? area.Name : string.Empty;

            rows.Add((
                new TodayRow(
                    new TaskId(task.Id),
                    task.Name,
                    task.NextStepText,
                    list.AreaId,
                    areaName,
                    task.Priority,
                    task.Starred,
                    verdict.Overdue,
                    verdict.ReasonDate,
                    task.Recurrence is not null),
                verdict));
        }

        // Overdue first (spec §5), then the shared task sort order (spec §3.4).
        return
        [
            .. rows
                .OrderByDescending(entry => entry.Verdict.Overdue)
                .ThenBy(entry => TaskSort.Key(
                    entry.Row.Starred, entry.Row.Priority, entry.Verdict.ReasonDate, entry.Row.Name))
                .Select(entry => entry.Row)
        ];
    }
}
```

```csharp
using System.Text.Json;
using Marten;
using PSPad.Contracts;
using PSPad.Domain;
using PSPad.Domain.Common;
using PSPad.Server.Commands;

namespace PSPad.Server.Api;

public static class CommandEndpoints
{
    static readonly IReadOnlyDictionary<string, Type> Allowed =
        typeof(DomainMarker).Assembly
            .GetTypes()
            .Where(type => type is { IsAbstract: false, IsInterface: false })
            .Where(typeof(ICommand).IsAssignableFrom)
            .ToDictionary(type => type.Name, type => type);

    public static void MapCommandEndpoints(this WebApplication app)
    {
        app.MapPost("/api/commands", async (
            CommandBatch batch,
            HttpContext context,
            IDocumentSession session,
            CancellationToken cancellationToken) =>
        {
            if (CurrentUser.From(context) is not { } user)
                return Results.Unauthorized();

            var outcomes = new List<CommandOutcome>();

            foreach (var envelope in batch.Commands)
            {
                if (!Allowed.TryGetValue(envelope.Type, out var type))
                    return Results.BadRequest(new { error = $"Unknown command type {envelope.Type}." });

                if (envelope.Payload.Deserialize(type) is not ICommand command)
                    return Results.BadRequest(new { error = $"Malformed payload for {envelope.Type}." });

                if (command.UserId != user)
                    return Results.Forbid();

                var result = await CommandProcessor.ExecuteAsync(session, command, cancellationToken);

                outcomes.Add(new CommandOutcome(
                    result.CommandId, result.Accepted, result.ErrorCode, result.ErrorMessage));
            }

            await session.SaveChangesAsync(cancellationToken);

            var version = await CurrentVersionAsync(session, cancellationToken);

            return Results.Ok(new CommandBatchResponse(outcomes, version));
        });
    }

    /// <summary>The highest event sequence in the store — the marker a client syncs from.</summary>
    public static async Task<long> CurrentVersionAsync(
        IQuerySession session, CancellationToken cancellationToken)
    {
        var latest = await session.Events
            .QueryAllRawEvents()
            .OrderByDescending(e => e.Sequence)
            .FirstOrDefaultAsync(cancellationToken);

        return latest?.Sequence ?? 0;
    }
}
```

```csharp
using System.Text.Json;
using Marten;
using PSPad.Contracts;
using PSPad.Domain.Common;
using PSPad.Server.History;
using PSPad.Server.Projections;
using PSPad.Server.Today;

namespace PSPad.Server.Api;

public static class QueryEndpoints
{
    public static void MapQueryEndpoints(this WebApplication app)
    {
        app.MapGet("/api/sync", async (
            long since,
            HttpContext context,
            IQuerySession session,
            CancellationToken cancellationToken) =>
        {
            if (CurrentUser.From(context) is not { } user)
                return Results.Unauthorized();

            var areas = await Changed<AreaView>(session, user, since, cancellationToken);
            var lists = await Changed<ListView>(session, user, since, cancellationToken);
            var tasks = await Changed<TaskView>(session, user, since, cancellationToken);
            var goals = await Changed<GoalView>(session, user, since, cancellationToken);
            var inbox = await Changed<InboxView>(session, user, since, cancellationToken);

            var version = await CommandEndpoints.CurrentVersionAsync(session, cancellationToken);

            return Results.Ok(new SyncResponse(areas, lists, tasks, goals, inbox, version));
        });

        app.MapGet("/api/today", async (
            HttpContext context,
            IQuerySession session,
            CancellationToken cancellationToken) =>
        {
            if (CurrentUser.From(context) is not { } user)
                return Results.Unauthorized();

            var zone = ZoneFor(context);
            var rows = await TodayQuery.RunAsync(
                session, user, zone, DateTimeOffset.UtcNow, cancellationToken);

            return Results.Ok(rows);
        });

        app.MapGet("/api/history", async (
            HttpContext context,
            IQuerySession session,
            int? limit,
            CancellationToken cancellationToken) =>
        {
            if (CurrentUser.From(context) is not { } user)
                return Results.Unauthorized();

            var entries = await HistoryQuery.RunAsync(
                session, user, from: null, to: null, limit ?? 100, cancellationToken);

            return Results.Ok(entries);
        });
    }

    /// <summary>
    /// The client sends its zone per request. Plan 05 moves the default onto the
    /// User aggregate; the header stays as an override for a travelling device.
    /// </summary>
    static TimeZoneInfo ZoneFor(HttpContext context)
    {
        var id = context.Request.Headers["X-Time-Zone"].ToString();

        if (string.IsNullOrWhiteSpace(id))
            return TimeZoneInfo.Utc;

        try
        {
            return TimeZoneInfo.FindSystemTimeZoneById(id);
        }
        catch (TimeZoneNotFoundException)
        {
            return TimeZoneInfo.Utc;
        }
    }

    static async Task<IReadOnlyList<JsonElement>> Changed<TView>(
        IQuerySession session, UserId user, long since, CancellationToken cancellationToken)
        where TView : class
    {
        var rows = await session.Query<TView>()
            .Where(row => Marten.Linq.MartenExtensions.MatchesSql<TView>(
                row, "(data ->> 'UserId')::uuid = ? and (data ->> 'Version')::bigint > ?",
                user.Value, since))
            .ToListAsync(cancellationToken);

        return [.. rows.Select(row => JsonSerializer.SerializeToElement(row))];
    }
}
```

matters: rows of this user changed after the marker.
