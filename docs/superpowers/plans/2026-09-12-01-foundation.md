# Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the solution skeleton, the development stack and the test
machinery, so every later plan has projects to write into and guards that fail
when the architecture is violated.

**Architecture:** Eight projects under `src/` (API, client, three shared, three
modules) plus four test projects. References run one way only, and three tests
enforce that. MongoDB runs as a single-node replica set everywhere — development,
production and Testcontainers — because transactions require one.

**Tech Stack:** .NET 10, xUnit v3, Testcontainers 4.x, MongoDB 8, Keycloak 26,
Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-12-slice-1-design.md`

## Global Constraints

- Target framework `net10.0`, `Nullable` enable, `TreatWarningsAsErrors` true — already set in `Directory.Build.props`; do not weaken it.
- No comments in code. A genuinely counter-intuitive constraint gets one line saying *why*, never *what*.
- Every test class carries `[UnitTest]` or `[IntegrationTest]`. An unmarked test class fails the build.
- `PSPad.Module.Tasks` and `PSPad.Abstractions` reference no infrastructure assembly: no `MongoDB.*`, no `Microsoft.AspNetCore.*`, no `System.Net.Http`.
- `PSPad.Infrastructure` references no module assembly.
- MongoDB image `mongo:8`, replica set name `rs0`.
- Keycloak image `quay.io/keycloak/keycloak:26.0`, realm `pspad`.
- Code, comments, commits and docs in English.
- License GPL v3; every dependency must be compatible.

using System.Reflection;

namespace PSPad.TestInfrastructure;

public static class TestCategoryGuard
{
    public static void AssertEveryTestClassIsCategorised(Assembly assembly)
    {
        var unmarked = assembly.GetTypes()
            .Where(HasTestMethods)
            .Where(type => !IsCategorised(type))
            .Select(type => type.FullName!)
            .OrderBy(name => name)
            .ToArray();

        Assert.True(
            unmarked.Length == 0,
            $"Test classes without a category attribute: {string.Join(", ", unmarked)}");
    }

    static bool HasTestMethods(Type type) =>
        type.GetMethods(BindingFlags.Public | BindingFlags.Instance)
            .Any(method => method.GetCustomAttributes()
                .Any(attribute => attribute is FactAttribute or TheoryAttribute));

    static bool IsCategorised(Type type) =>
        type.GetCustomAttribute<UnitTestAttribute>() is not null ||
        type.GetCustomAttribute<IntegrationTestAttribute>() is not null;
}
```

`PSPad.TestInfrastructure` needs the xUnit packages to compile this; the `xunit3`
template already added them.

using System.Reflection;

namespace PSPad.TestInfrastructure;

public static class AssemblyReferenceGuard
{
    public static void AssertReferencesNone(Assembly assembly, params string[] forbiddenPrefixes)
    {
        var violations = assembly.GetReferencedAssemblies()
            .Select(reference => reference.Name!)
            .Where(name => forbiddenPrefixes.Any(prefix =>
                name.StartsWith(prefix, StringComparison.Ordinal)))
            .OrderBy(name => name)
            .ToArray();

        Assert.True(
            violations.Length == 0,
            $"{assembly.GetName().Name} must not reference: {string.Join(", ", violations)}");
    }
}

      retries: 20

  mongo-data:

networks:
  pspad:

The healthcheck doubles as the replica-set initiator: the first probe finds no
configuration, runs `rs.initiate`, and every later probe reports status. That
keeps a one-node replica set working without a second container or an init script.

using MongoDB.Driver;
using Testcontainers.MongoDb;

namespace PSPad.TestInfrastructure;

public sealed class MongoFixture : IAsyncLifetime
{
    readonly MongoDbContainer _container = new MongoDbBuilder()
        .WithImage("mongo:8")
        .WithReplicaSet()
        .Build();

    IMongoClient _client = null!;

    public string ConnectionString => _container.GetConnectionString();

    public IMongoClient Client => _client;

    public IMongoDatabase Database => _client.GetDatabase("pspad_test");

    public async ValueTask InitializeAsync()
    {
        await _container.StartAsync();
        _client = new MongoClient(ConnectionString);
    }

    public ValueTask DisposeAsync() => _container.DisposeAsync();
}
```

If the installed `Testcontainers.MongoDb` has no `WithReplicaSet()`, drop to a raw
container instead — the transaction test above is what tells you either way:

```csharp
    readonly IContainer _container = new ContainerBuilder()
        .WithImage("mongo:8")
        .WithCommand("mongod", "--replSet", "rs0", "--bind_ip_all")
        .WithPortBinding(27017, true)
        .WithWaitStrategy(Wait.ForUnixContainer().UntilCommandIsCompleted(
            "mongosh", "--quiet", "--eval",
            "try { rs.status().ok } catch (e) { rs.initiate().ok }"))
        .Build();
```

with `ConnectionString` built as
`$"mongodb://localhost:{_container.GetMappedPublicPort(27017)}/?directConnection=true"`.
`directConnection=true` matters: without it the driver follows the replica-set
host name advertised by the container, which is unreachable from the host.
