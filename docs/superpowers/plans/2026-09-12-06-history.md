# History Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the event log into a readable account of what the user did, paged
newest first, with no second record of anything.

**Architecture:** `PSPad.Module.History` reads `events` through one narrow port
and turns stored events into sentences. The API pages it by sequence. Nothing
writes here — if the history is missing something, the fix is in the handler that
failed to emit an event, never a new table.

**Tech Stack:** .NET 10, MongoDB.Driver, Minimal API, xUnit v3, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-09-12-slice-1-design.md`

## Global Constraints

- Target framework `net10.0`, `Nullable` enable, `TreatWarningsAsErrors` true.
- No comments in code, except one line for a genuinely counter-intuitive constraint saying *why*.
- Every test class carries `[UnitTest]` or `[IntegrationTest]`.
- `PSPad.Module.History` references `PSPad.Abstractions` and `PSPad.Contracts` only. It reaches the log through an interface the API implements.
- History comes only from the event log. Never add a table, a column or a field whose purpose is recording what happened.
- Paging is by sequence, descending. Never by timestamp.
- Code, comments, commits and docs in English.

- [ ] **Step 6: Write the reader**

```csharp
using PSPad.Contracts;

namespace PSPad.Module.History;

public sealed class HistoryReader(IEventLog log)
{
    const int DefaultLimit = 50;
    const int MaximumLimit = 200;

    public async Task<IReadOnlyList<HistoryEntry>> ReadAsync(
        Guid userId, long? before, int limit, CancellationToken ct)
    {
        var page = limit switch
        {
            < 1 => DefaultLimit,
            > MaximumLimit => MaximumLimit,
            _ => limit
        };

        var events = await log.ReadAsync(userId, before, page, ct);

        return events
            .Select(recorded => new HistoryEntry(
                recorded.Seq,
                recorded.At,
                recorded.AggregateType,
                recorded.AggregateId,
                HistoryDescriptions.For(recorded.Type)))
            .ToArray();
    }
}
```

- [ ] **Step 3: Write the log adapter**

```csharp
using MongoDB.Driver;
using PSPad.Contracts;
using PSPad.Infrastructure.Mongo;
using PSPad.Module.History;

namespace PSPad.Api.History;

public sealed class MongoEventLog(MongoContext context) : IEventLog
{
    public async Task<IReadOnlyList<RecordedEvent>> ReadAsync(
        Guid userId, long? before, int limit, CancellationToken ct)
    {
        var filter = Builders<StoredEvent>.Filter.Eq(entry => entry.UserId, userId);

        if (before is not null)
        {
            filter &= Builders<StoredEvent>.Filter.Lt(entry => entry.Seq, before.Value);
        }

        var events = await context.Collection<StoredEvent>("events")
            .Find(filter)
            .SortByDescending(entry => entry.Seq)
            .Limit(limit)
            .ToListAsync(ct);

        return events
            .Select(entry => new RecordedEvent(
                entry.Seq, entry.AggregateType, entry.AggregateId, entry.Type, entry.Payload, entry.At))
            .ToArray();
    }
}
```
